# 🚍 TicketHub - Online Ticket Booking Platform

A modern MERN Stack based Online Ticket Booking Platform where users can discover and book Bus, Train, Launch and Flight tickets. The platform supports three different user roles (User, Vendor and Admin) with secure authentication, ticket management, booking system and Stripe payment integration.

## 🎯 Project Purpose

TicketHub is designed to provide a complete online ticket booking solution where users can search, view and book transport tickets while vendors can manage their own tickets and administrators can control the whole platform.

The project demonstrates full-stack development using the MERN Stack, authentication, authorization, payment gateway integration, dashboard management and responsive UI.
